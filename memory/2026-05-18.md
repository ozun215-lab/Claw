## 오늘 수행한 작업

### 문제 1: swtpm_user 미설정
- `/etc/libvirt/qemu.conf`에 `swtpm_user`/`swtpm_group` 설정 없음 → root 권한으로 swtpm_setup 실행
- `/var/lib/swtpm-localca/` 권한 오류로 EK 인증서 생성 실패
- **해결**: `qemu.conf`에 `swtpm_user = "tss"`, `swtpm_group = "tss"` 추가 후 libvirtd 재시작

### 문제 2: Windows 인스톨러 TPM 미인식
- WinPE 환경에서 `Get-Tpm → TpmPresent: False` — WinPE 한계
- `wmic win32_tpm` → "사용할 수 있는 인스턴스가 없습니다"
- **결론**: WinPE에서 TPM 미인식은 swtpm 문제 아님, 인스톨러 한계
- **해결**: LabConfig 우회 레지스트리로 설치 진행

### 문제 3: smm=on 미설정
- 최초 win11-25h2 VM에 smm 미설정
- `virsh edit`으로 `<smm state='on'/>` 추가
- QEMU 명령줄에서 `smm=on` 확인됨

### 문제 4: secure='yes' 미설정
- loader에 `secure='yes'` 없음 → `-global driver=cfi.pflash01,property=secure,value=on` 미전달
- `virsh edit`으로 `secure='yes'` 추가 후 확인됨

### 문제 5: watchdog 강제 재부팅
- QEMU 명령줄에 `-device i6300esb -watchdog-action reset` 있음
- Windows 응답 느릴 때 watchdog이 VM 강제 reset
- **해결**: `virsh edit`으로 `<watchdog model='i6300esb' action='reset'/>` 제거

### 문제 6: NVRAM 크기 오해
- OVMF 2025 기준 `OVMF_VARS_4M.ms.fd` = 528KB (정상)
- "_4M"은 4MB 플래시 레이아웃 의미, 파일 자체가 4MB가 아님

## 주요 결정사항

- **TPM 우회 설치**: WinPE에서 TPM 미인식은 정상 동작 — LabConfig 우회 후 설치, 실제 OS에서 TPM 확인
