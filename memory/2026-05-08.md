### 아키텍처 결정 사항
- **3계층 backing chain**: master(압축,chmod444) → backup(압축) → overlay(falloc)
- **pre-backup.qcow2**: Windows Update 직전 overlay 스냅샷, 1개만 유지 (압축 delta)
- **commit 대상**: backup만 (master에는 절대 commit 금지)
- **falloc**: overlay 전용 (런타임 I/O 안정성)
- **rollback 3단계**: pre → backup → master

### 스크립트 목록 (모두 문서에 포함)
- `init.sh` — 초기 3계층 체인 생성
- `vm-pre-update.sh` — Update 전 pre-backup 생성 + overlay 재생성
- `vm-update-commit.sh` — overlay → backup commit + 압축 재변환 + overlay 재생성
- `vm-rollback.sh [pre|backup|master]` — 3단계 롤백
- `status.sh` — 체인 상태 및 VM 상태 조회
