## Session: Google Chat Channel Setup & Troubleshooting (~19:55–20:12 KST)

### Problem
Google Chat 채널에서 메시지를 보내도 봇이 응답하지 않음.

### Root cause
**ngrok free tier 인터스티셜 차단** — ngrok 무료 플랜은 외부 서버(Google 포함)에서 접속 시 브라우저 확인 페이지를 반환하여 Google Chat의 webhook POST가 게이트웨이까지 도달하지 못함.

### Diagnosis steps
1. `plugins.entries.googlechat` status: "disabled" → 재시작 시도 (이것만으로는 해결 안 됨)
2. ngrok 터널 자체는 살아있고 로컬 POST 테스트는 200 응답
3. 게이트웨이 로그에 Google Chat 인바운드 메시지 기록 전무
4. ngrok inspect API로 확인 — 외부(Google)에서 오는 POST 없음
5. Google Cloud Console 설정 확인 — App URL, HTTP endpoint 모두 올바름
6. 결론: ngrok free tier의 인터스티셜이 Google 서버 요청을 차단

### Solution applied
- **Cloudflare Tunnel (cloudflared)** 설치 및 사용
  - 설치 경로: `C:\Users\zunn\AppData\Local\Programs\cloudflared\cloudflared.exe`
  - 실행: `cloudflared tunnel --url http://localhost:28874`
  - 생성된 URL: `https://summary-differ-nebraska-words.trycloudflare.com`
- OpenClaw config 변경:
  - `channels.googlechat.webhookUrl` → `https://summary-differ-nebraska-words.trycloudflare.com/googlechat`
  - `channels.googlechat.audience` → 동일
- **주의**: trycloudflare.com URL은 cloudflared 재시작 시 변경됨 (임시 URL)
