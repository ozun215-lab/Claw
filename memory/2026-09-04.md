3. **21개 패키지 건너뜀**: systemd, dnf, grub2, elfutils 관련 충돌 패키지

### 올바른 오프라인 설치 방법 (다음에 참고)
```bash
# 핵심: 외부 레포 비활성화 후 설치
dnf install --disablerepo="*" -y ./*.rpm

# 또는 충돌 패키지 제외
dnf install --disablerepo="*" --exclude=systemd*,dnf*,grub2*,elfutils* -y ./*.rpm
```

### 교훈
1. 오프라인 설치 시 **반드시 `--disablerepo="*"` 사용**
2. OS 버전과 RPM 버전 일치 확인 (el9_7 ↔ Rocky 9.7)
3. fresh install 후 **dnf update 하지 않고** 바로 로컬 RPM 설치
4. 보호 패키지(systemd/dnf/grub2) 다운그레이드 절대 금지
