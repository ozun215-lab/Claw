Internal VM(Win11)  저지연 튜닝 권장사항을
아래와 같이 정리하여 보고드립니다. 상세 내용은 첨부 문서를 참고해 주십시오.


1. 저지연(low-latency) 튜닝 권장사항
   -------------------------------
   노트북 + VM 2대 동시 운영 환경에 맞춰 부작용이 적은 항목 위주로
   적용을 권장합니다. CPU 핀닝/코어 격리는 노트북 환경 부적합으로 제외.

   [우선순위 2 - 효과 큼, 부작용 없음]
   - <ioapic driver='kvm'/> 추가 (인터럽트 in-kernel 처리)
   - Hyper-V enlightenment 확장: ipi, frequencies, reset 추가
   - <kvm><hidden/><poll-control/></kvm> 추가
   - CPU에 invtsc feature 추가
   - clock에 TSC native 타이머 추가

   [우선순위 3 - 메모리/디스크 안정성]
   - <memballoon model='none'/> (저지연 목적이면)
   - 디스크 discard='unmap' (TRIM 활성)


   [우선순위 4 - 정리(선택)]
   - 입력 디바이스 중복 제거 (PS/2 mouse, virtio mouse/keyboard)
   - 미사용 PCI 브리지 제거


2. 이미 양호한 항목
   -------------------------------
   ✓ Transparent Hugepage = madvise (QEMU/KVM 최적)
   ✓ host-passthrough CPU 모드
   ✓ Hyper-V enlightenment 다수 적용
   ✓ virtio-blk + iothread + multi-queue
   ✓ Q35 + OVMF + TPM 2.0 (Win11 표준 구성)


3. 호스트 측 점검 권장
   -------------------------------
   - KSM 비활성 (systemctl disable --now ksm ksmtuned)
   - CPU governor를 performance로 (전원 연결 상태에서)
   - THP defrag = madvise 확인
   - 호스트 코어 수 대비 VM 두 대의 vCPU 합계 적정성 검토


4. 적용 절차 권장 순서
   -------------------------------
   ① XML / 디스크 이미지 백업
   ② 비디오 모델 변경 → VM 부팅 가능화
   ③ 게스트에 virtio-gpu 드라이버 설치
   ④ 우선순위 2 항목 일괄 반영
   ⑤ 우선순위 3 항목 반영
   ⑥ LatencyMon으로 베이스라인 측정
   ⑦ 우선순위 4 정리 (선택)

   각 단계마다 VM 시작 정상 여부 확인 후 다음 단계 진행.


5. 추가 확인 필요 사항
   -------------------------------
   - 백업/스냅샷 정책
