### 🔥 부족분 4,300만원 보완 대안 4가지

#### 대안 A: **037 상가 임대료 일부 인정** ⭐ 가장 추천
```

→ 입증 비율 100.0% (정확히 충당)

장점: 가장 자연스럽고 합리적
단점: "사업운영비 대출 충당" 입증 자료 필요
필요 자료: IBK 사업운영 대출 약정서 + 사업운영비 영수증
```

#### 대안 B: **김수동 자금을 증여로 신고**
```
김수동 6,500만원을 차용이 아닌 증여로 신고
→ 증여세 약 650만원 납부 (10% 세율 가정)
→ 입증 비율 104.2% (시나리오 ①과 동일)

장점: 차용증 입증 부담 회피
단점: 증여세 납부 (약 650만), 김수동 - 박영준 관계 명확화 필요
```

#### 대안 C: **본인 다른 보유 자산 입증**
```
2022-02-23 시점에 보유 중이던 자기자금 입증
- 예금, 주식, 펀드, 채권 등의 잔액
- 부동산 매도 자금 잔존분
- 보유 가상화폐 매도 자금 (단, 가상자산 별도 이슈)

장점: 자기자금이므로 가장 깔끔
단점: 다른 계좌·자산 거래내역 추가 필요

```

- 형제·자매 차용

장점: 가족 간 자금 이동은 자연스러움
단점: 차용 사실 입증 자료 필요 (송금 기록 + 차용증)
