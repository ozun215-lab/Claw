제목: [NST] KVM/QEMU Windows 11 VM 이벤트 로그 분석 결과 요약

안녕하세요.

NST 시스템의 KVM/QEMU 기반 Windows 11 25H2 VM 이벤트 로그(스크린샷 14장, 약 3,879건)를 분석한 결과를 요약하여 공유드립니다.

■ 결론
시스템 장애를 시사하는 로그는 없습니다. 하드웨어 오류, 블루스크린, 서비스 크래시 등 실질적 문제 이벤트는 한 건도 없으며, 발견된 오류/경고는 전부 가상머신 환경 특성상 발생하는 무해한 이벤트입니다.

■ 주요 이벤트 및 조치
1. Wininit 15 (VBS/Credential Guard 미기동)
   - 원인: KVM 게스트에 중첩 가상화 미노출로 보안 커널 기동 실패
   - 조치: VM 내에서 "bcdedit /set hypervisorlaunchtype off" 실행 권장 (경고 제거 + 성능 향상)

2. TPM-WMI 1801 (Secure Boot 2023 인증서 미적용) — 유일하게 조치 필요
   - 원인: 호스트 OVMF 펌웨어(Debian 2025.02-8)에 Microsoft 2023 인증서 미포함 (Debian 버그 #1134793)
   - 기존 2011 인증서는 2026년 6~10월 순차 만료 → 연내 조치 권장
   - 조치: 호스트 OVMF를 2025.11-5 이상으로 업데이트 + VM NVRAM(VARS) 갱신
   - 호스트가 Debian 11인 경우: backports 종료 상태이므로 (a) 호스트 업그레이드, (b) virt-fw-vars로 인증서 수동 주입, (c) 신버전 OVMF 바이너리 추출 사용 중 택1
   - ⚠️ VARS 재생성 시 BitLocker 사용 중이면 복구 키 사전 확보 필수

3. 기타 (조치 불필요)
   - DCOM 10010/10016: VM 부팅 지연 기인 / MS 공식 무해 이벤트 → 무시
   - SCM 7006: VBS 비활성화 시 함께 해소 예상 → 관찰
   - WinSrvExt 100 (종료 5초 지연), User32 1074 (정상 종료 기록) → 정상

■ 요약표
 우선순위 | 항목                  | 조치                          | 시급성
 1        | Secure Boot 인증서    | OVMF 업데이트 + VARS 갱신     | 2026년 내
 2        | VBS 미기동            | hypervisorlaunchtype off      | 선택
 3        | 나머지 이벤트         | 없음 (정상/무시)              | —

상세 분석 및 확인 명령어는 첨부 보고서를 참고 부탁드립니다.
